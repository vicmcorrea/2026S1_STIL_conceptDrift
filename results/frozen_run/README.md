# Frozen paper-figure inputs

These derived tables come from experiment `ba65fe5b9cce` and are the minimal
inputs required by `run/pipeline/generate_paper_figures.py`. They contain
aggregate counts, method scores, ranks, and trajectories, but no speech text or
sampled contextual occurrences.

The full intermediate run is not included because its trained models,
preprocessed corpus, and occurrence embeddings require approximately 8.6 GB.
